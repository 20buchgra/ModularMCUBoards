# ModularMCUBoards

## Designing modular raspberry pi // teensy mcu boards
attempting to design N-core boards for distributed processing

## RP2354A
The RP2354A provides dual-core operation including floating point, 2MB flash, and 30 GPIO pins
[product link](https://www.raspberrypi.com/products/rp2350/)
The ability to flash the full pi OS is vital for testing, though the final implementation should be a headless MCU

### Single Board
The first board, found in [v0p0](/RPI_2354A_v0p0) provides a simple implementation of the basic core following the [guide](https://pip-assets.raspberrypi.com/categories/1214-rp2350/documents/RP-008280-DS-2-hardware-design-with-rp2350.pdf)
It largely resembles the Pico 2W (but costs more XD)
Testing is to be done!
